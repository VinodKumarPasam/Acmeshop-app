# 🛒 AcmeShop - Microservices DevOps Project

## 📖 Project Overview

AcmeShop is a full-stack microservices-based e-commerce application built to learn and demonstrate modern DevOps practices.

The primary goal of this project is **not** to build an e-commerce application, but to use it as a platform for learning real-world DevOps concepts from development to production deployment.

---

## 🎯 Project Objectives

This project is designed to gain hands-on experience with:

- Git & GitHub
- Docker
- Docker Compose
- CI/CD with Jenkins
- Kubernetes
- Monitoring with Prometheus & Grafana
- Logging
- AWS Cloud
- Terraform
- Production-grade deployment practices
